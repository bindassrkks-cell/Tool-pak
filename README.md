## 📱 Overview

**PAK-OBB TOOL** is a high-performance Android utility engineered to **Unpack**, **Inject (Chams / Modified Assets)**, and **Repack** Unreal Engine `.pak` and `.obb` patch archives directly on mobile devices without root access or PC dependency.

Built with a responsive **Cyberpunk Dark HUD** theme using **Jetpack Compose** and powered by an embedded **Python 3.10 + Chaquopy** binary engine (`pycryptodome`, `zstandard`, `zlib`).

---

## 🎨 UI / UX Design & Layout

The app uses a dedicated **Cyberpunk Navy Terminal** aesthetic with real-time feedback, high-contrast neon accents, and single-tap operations.
